# Elastic Slurm HPC Stack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a three-VM Slurm cluster beside the k3s lab, with shared storage, Spack-built modules,
Prometheus/Grafana monitoring and compute nodes that Slurm powers on and off through a small API on the Mac.

**Architecture:** A separate Terraform root module (`terraform/hpc/`, own state) creates `hpc-head`, `hpc-node-1` and
`hpc-node-2` and writes `ansible/inventory/hpc.yml`. `ansible/site-hpc.yml` configures them; Slurm's power-saving
hooks call `power-api/server.py` on the Mac, which only runs `multipass start|stop|info`. A separate
`monitoring-hpc.yml` wires the Slurm exporter into the existing k3s Prometheus and Grafana.

**Tech Stack:** Terraform ≥ 1.9 + `larstobi/multipass ~> 1.4.3`, Ansible (ansible-core 2.21, ansible-lint 26.9),
Ubuntu 24.04 (`slurmctld`/`slurmd` 23.11.4, `munge`, `nfs-kernel-server`, `lmod`), Spack v1.2.2, rivosinc
prometheus-slurm-exporter v1.8.0, Python 3 stdlib (+ pytest 9.1.1 for tests), Bash, promtool (Prometheus 3.15.0).

**Spec:** `docs/superpowers/specs/2026-10-12-hpc-slurm-design.md`. Read §10 (revisions) first: it overrides
earlier sections.

## Global Constraints

- Terraform owns what exists, Ansible owns what is on it; the power API only starts/stops existing VMs.
- The k3s stack (`terraform/`, `site.yml`, `make up/down/test`) must keep working unchanged in behaviour.
- `make down` must never touch HPC VMs; `make hpc-down` must never touch k3s VMs.
- Every version pinned in one place: Terraform in `versions.tf`, Ansible in `ansible/group_vars/all.yml`.
- Secrets live only in `.secrets/` (git-ignored) on the Mac and root/slurm-only files on the head; never in git,
  never in process arguments, never echoed (`no_log: true`).
- Power API: binds one address (never `0.0.0.0`, `::` or empty), bearer token, node names must match
  `hpc-node-[0-9]+` (ASCII digits only), runs `multipass` with an argument list, never a shell string.
- Compute node names must match `hpc-node-[0-9]+` (the API rejects anything else).
- VM sizes: head 2 vCPU / `2G` / `15G`; computes 2 vCPU / `1536M` / `15G`. Slurm `RealMemory=1200`, `CPUs=2`.
- Slurm: partitions `short` (default, `MaxTime=00:15:00`) and `long` (`02:00:00`); `SuspendTime=120`,
  `SuspendTimeout=60`, `ResumeTimeout=300`, `ResumeRate=0`, `SuspendRate=0`, `ReturnToService=2`,
  `MinJobAge=600`, `SrunPortRange=60001-60100`, `JobCompType=jobcomp/filetxt`.
- Shared storage at `/shared` (head exports `/srv/shared`) and `/opt/spack` (read-only on computes). Never `/home`.
- Firewall and NFS rules by HPC subnet, not per IP.
- Power API port 8765; exporter port 9092.
- Makefile must work with GNU make 3.81: no `.ONESHELL`; multi-line logic goes in `scripts/*.sh` with
  `set -euo pipefail`; a recipe line with a pipe starts with `set -o pipefail;`.
- Match the repo's style: comments explain *why*, cite the spec section, no comment on obvious lines.
- Commit after every task with the attribution trailer:

  the repo owner first (the repo is public).

## Review Focus

1. **Power API not running when Slurm needs a node** (Mac asleep, process killed): the resume hook must log the
   cause in `/var/log/slurm/power.log`, the node must go `DOWN`, and the runbook (`scontrol update ... State=RESUME`)
   must bring it back. Test: Task 6, Step 10.
2. **Compute node leases a new IP after a restart**: the resume hook must call
   `scontrol update NodeAddr=<new ip>`. Test: Task 6, Step 1 (`test_resume_updates_node_addr`).
3. **Re-running configuration while compute nodes are powered off**: `make hpc-configure` must hold, wake, configure
   and release, not fail on unreachable hosts. Test: Task 8 (`hpc-test.sh` runs idempotency after the elastic demo,
   when nodes are off).
4. **A job asks for more memory than any node has** (`--mem=4G`): `sbatch` must refuse at submit time, not leave a job
   pending forever. Test: Task 4, verify play.
5. **`.secrets/power-api.token` missing when Ansible runs**: `make hpc-configure` must create it first rather than fail
   inside a file lookup. Test: Task 6, Step 9.

```python
#!/usr/bin/env python3
"""Power API for the lab's elastic Slurm nodes (spec §5.1).

Slurm's resume/suspend hooks on hpc-head call this on the Mac. It only ever runs
`multipass start|stop|info` as an argument list, for names matching hpc-node-<digits>,
and only for callers presenting the bearer token. It binds one address (the Multipass
network), never a wildcard, so nothing else on the LAN can reach it.
"""
import argparse
import hmac
import json
import re
import subprocess
import sys
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import parse_qs, urlparse

NODE_RE = re.compile(r"hpc-node-[0-9]+", re.ASCII)
ROUTES = {("POST", "/start"): "start", ("POST", "/stop"): "stop", ("GET", "/ip"): "ip"}
WILDCARD_BINDS = {"", "0.0.0.0", "::"}


def valid_node(name):
    return NODE_RE.fullmatch(name) is not None


def run_multipass(args):
    return subprocess.run(["multipass", *args], capture_output=True, text=True, timeout=180, check=False)


def make_handler(token, runner):
    expected = f"Bearer {token}".encode()

    class Handler(BaseHTTPRequestHandler):
        def _reply(self, status, body):
            data = json.dumps(body).encode()
            self.send_response(status)
            self.send_header("Content-Type", "application/json")
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)

        def _handle(self, method):
            url = urlparse(self.path)
            action = ROUTES.get((method, url.path))
            if action is None:
                return self._reply(404, {"error": "not found"})
            # Auth before validating input, so unauthenticated callers learn nothing about the rules.
            if not hmac.compare_digest(self.headers.get("Authorization", "").encode(), expected):
                return self._reply(401, {"error": "unauthorized"})
            nodes = parse_qs(url.query, keep_blank_values=True).get("node", [])
            if len(nodes) != 1 or not valid_node(nodes[0]):
                return self._reply(400, {"error": "node must be exactly one hpc-node-<number>"})
            node = nodes[0]
            args = ["info", node, "--format", "json"] if action == "ip" else [action, node]
            result = runner(args)
            if result.returncode != 0:
                return self._reply(502, {"error": (result.stderr or result.stdout).strip()})
            if action == "ip":
                ipv4 = json.loads(result.stdout).get("info", {}).get(node, {}).get("ipv4") or []
                return self._reply(200, {"node": node, "ip": ipv4[0] if ipv4 else None})
            return self._reply(200, {"node": node, "action": action})

        def do_GET(self):  # noqa: N802 (http.server naming)
            self._handle("GET")

        def do_POST(self):  # noqa: N802
            self._handle("POST")

    return Handler


def make_server(bind, port, token, runner=run_multipass):
    return ThreadingHTTPServer((bind, port), make_handler(token, runner))


def main(argv):
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--bind", required=True, help="the Mac's address on the Multipass network")
    parser.add_argument("--port", type=int, default=8765)
    parser.add_argument("--token-file", required=True)
    args = parser.parse_args(argv)
    if args.bind in WILDCARD_BINDS:
        sys.exit(f"refusing to bind {args.bind!r}: pass the Multipass network address")
    with open(args.token_file, encoding="utf-8") as fh:
        token = fh.read().strip()
    if not token:
        sys.exit(f"empty token in {args.token_file}")
    srv = make_server(args.bind, args.port, token)
    print(f"power-api listening on {args.bind}:{args.port}", flush=True)
    srv.serve_forever()


if __name__ == "__main__":
    main(sys.argv[1:])
```

```bash
#!/usr/bin/env bash
# Runs an HPC playbook action against inventory/hpc.yml. Task 6 adds the Slurm power hold around it.
#   configure    -> site-hpc.yml
#   verify       -> verify-hpc.yml
#   idempotency  -> site-hpc.yml twice-run check (scripts/check-idempotent.sh)

cd "$(dirname "$0")/.."
action=${1:?usage: hpc-run.sh configure|verify|idempotency}

esac
```

```bash
#!/usr/bin/env bash
# Re-runs a playbook and fails if any host reports a change (spec §5).
# PLAYBOOK and INVENTORY default to the k3s stack; the HPC stack passes its own.
set -euo pipefail
cd "$(dirname "$0")/../ansible"
playbook=${PLAYBOOK:-site.yml}
inventory_args=()
[ -n "${INVENTORY:-}" ] && inventory_args=(-i "$INVENTORY")
# ${arr[@]+"${arr[@]}"}: an empty array is "unbound" under set -u in macOS bash 3.2.
out=$(ansible-playbook ${inventory_args[@]+"${inventory_args[@]}"} "$playbook" 2>&1) || { echo "$out"; exit 1; }
recap=$(echo "$out" | sed -n '/PLAY RECAP/,$p')
echo "$recap"
if echo "$recap" | grep -Eq 'changed=[1-9]'; then
  echo "FAIL: second run changed something; a role is not idempotent" >&2
  echo "$out" | grep -E '^(changed|TASK)' | grep -B1 '^changed' >&2 || true
  exit 1
fi
echo "idempotent: changed=0 on every host"
```

```bash
#!/usr/bin/env bash
# Slurm power-saving hook (spec §5.2). Installed as slurm-resume and slurm-suspend; the name it is
# called by picks the action. Slurm passes one argument, a host list such as hpc-node-[1-2], and runs
# it as SlurmUser. The token is read by curl from a header file, so it never shows up in `ps`.
set -euo pipefail

POWER_ENV=${POWER_ENV:-/etc/slurm/power-api.env}
HEADER_FILE=${HEADER_FILE:-/etc/slurm/power-api.header}
LOG=${POWER_LOG:-/var/log/slurm/power.log}
RESUME_TIMEOUT=${RESUME_TIMEOUT:-300}

case "$(basename "$0")" in
  slurm-resume) action=resume ;;
  slurm-suspend) action=suspend ;;
  *) echo "call as slurm-resume or slurm-suspend" >&2; exit 2 ;;
esac

log() { printf '%s %s %s\n' "$(date -u +%FT%TZ)" "$action" "$*" >>"$LOG"; }

# shellcheck source=/dev/null
. "$POWER_ENV"
: "${POWER_API_URL:?POWER_API_URL missing from $POWER_ENV}"

api() { # METHOD PATH NODE -> response body; any non-2xx is an error
  curl -fsS --max-time 180 -X "$1" -H "@$HEADER_FILE" "$POWER_API_URL$2?node=$3"
}

[ $# -eq 1 ] || { log "expected one host list, got $#"; exit 2; }

rc=0
for n in $(scontrol show hostnames "$1"); do
  if [ "$action" = suspend ]; then
    if api POST /stop "$n" >/dev/null 2>>"$LOG"; then log "$n stopped"; else log "$n stop FAILED"; rc=1; fi
    continue
  fi

  if ! api POST /start "$n" >/dev/null 2>>"$LOG"; then log "$n start FAILED"; rc=1; continue; fi
  # Leave Slurm 30 s of its ResumeTimeout for slurmd to register after we hand over.
  deadline=$((SECONDS + RESUME_TIMEOUT - 30))
  ip=""
  while [ -z "$ip" ] && [ "$SECONDS" -lt "$deadline" ]; do
    ip=$(api GET /ip "$n" 2>>"$LOG" | python3 -c 'import json, sys; print(json.load(sys.stdin).get("ip") or "")' || true)
    [ -n "$ip" ] || sleep 3
  done
  if [ -z "$ip" ]; then log "$n has no IP after start"; rc=1; continue; fi
  # Multipass may lease a different address after a restart (spec §9).
  scontrol update NodeName="$n" NodeAddr="$ip" NodeHostname="$n"
  log "$n started at $ip"
done
exit "$rc"
```

```bash
#!/usr/bin/env bash
# Starts or stops the power API on the Mac (spec §5.1). It binds to hpc-head's default gateway, which is
# the Mac's address on the Multipass network (spec §10.3), so it needs hpc-head to be running.
set -euo pipefail
cd "$(dirname "$0")/.."
pidfile=.secrets/power-api.pid
port=${POWER_API_PORT:-8765}

running() { [ -f "$pidfile" ] && kill -0 "$(cat "$pidfile")" 2>/dev/null; }

case "${1:?start|stop}" in
  start)
    if running; then echo "power-api already running (pid $(cat "$pidfile"))"; exit 0; fi
    gw=$(multipass exec hpc-head -- ip -4 route show default | awk '{print $3; exit}')
    [ -n "$gw" ] || { echo "could not read hpc-head's default gateway" >&2; exit 1; }
    nohup python3 power-api/server.py --bind "$gw" --port "$port" --token-file .secrets/power-api.token \
      >>.secrets/power-api.log 2>&1 &
    echo $! >"$pidfile"
    # Alive and enforcing auth: an unauthenticated call must get 401.
    for _ in $(seq 1 20); do
      code=$(curl -s -o /dev/null -w '%{http_code}' "http://$gw:$port/ip?node=hpc-node-1" || true)
      [ "$code" = 401 ] && { echo "power-api listening on $gw:$port (pid $(cat "$pidfile"))"; exit 0; }
      sleep 0.5
    done
    echo "power-api did not come up; see .secrets/power-api.log" >&2
    exit 1
    ;;
  stop)
    if running; then kill "$(cat "$pidfile")"; echo "power-api stopped"; fi
    rm -f "$pidfile"
    ;;
  *) echo "usage: power-api.sh start|stop" >&2; exit 2 ;;
esac
```

```bash
#!/usr/bin/env bash
# hold: stop Slurm powering compute nodes off and wake them, so Ansible can reach every node (spec §10.4).
# release: hand them back to power saving. Both are no-ops before slurmctld exists (first build).
set -euo pipefail
cd "$(dirname "$0")/.."
on_head() { multipass exec hpc-head -- "$@"; }

if ! on_head systemctl is-active --quiet slurmctld 2>/dev/null; then
  echo "slurmctld not running yet; nothing to ${1:-hold}"
  exit 0
fi
nodes=$(on_head sinfo -h -N -o '%N' | sort -u | paste -sd, -)

case "${1:?hold|release}" in
  hold)
    on_head sudo scontrol update SuspendExcNodes="$nodes"
    for n in ${nodes//,/ }; do
      on_head sudo scontrol update NodeName="$n" State=POWER_UP 2>/dev/null || true
    done
    for _ in $(seq 1 60); do
      states=$(on_head sinfo -h -N -o '%t' | sort -u | paste -sd' ' -)
      case "$states" in *'~'*|*'#'*|*'%'*|*down*) sleep 5 ;; *) echo "held, nodes up: $states"; exit 0 ;; esac
    done
    echo "nodes did not come up within 5 minutes (states: $states)" >&2
    exit 1
    ;;
  release)
    on_head sudo scontrol update SuspendExcNodes=""
    echo "released: power saving applies again"
    ;;
  *) echo "usage: hpc-hold.sh hold|release" >&2; exit 2 ;;
esac
```

```bash
#!/usr/bin/env bash
# Elastic-node demo (spec §7.2): both nodes off -> a job wakes them -> COMPLETED -> both off again.
# Prints the cold-start wait and the time back to powered-off.
set -euo pipefail
cd "$(dirname "$0")/.."
on_head() { multipass exec hpc-head -- "$@"; }
nodes=(hpc-node-1 hpc-node-2)

all_off() {
  [ "$(on_head sinfo -h -N -o '%t' | sort -u)" = "idle~" ] || return 1
  for n in "${nodes[@]}"; do
    multipass info "$n" --format json | jq -e --arg n "$n" '.info[$n].state == "Stopped"' >/dev/null || return 1
  done
}
job_state() { on_head scontrol show job "$1" -o | grep -o 'JobState=[A-Z_]*' | cut -d= -f2; }

echo "1/4 waiting for both nodes to be powered off (up to 6 min)"
start=$SECONDS
until all_off; do
  [ $((SECONDS - start)) -lt 360 ] || { echo "FAIL: nodes not powered off after 6 min" >&2; on_head sinfo -N; exit 1; }
  sleep 5
done
echo "    both powered off"

echo "2/4 submitting a two-node job"
job=$(on_head sudo -u ops sbatch --parsable -p short -N2 --chdir=/shared/ops --wrap 'srun hostname; sleep 10')
submitted=$SECONDS

echo "3/4 waiting for it to start and finish"
state=""
until [ "$state" = RUNNING ] || [ "$state" = COMPLETED ]; do
  [ $((SECONDS - submitted)) -lt 330 ] || { echo "FAIL: job $job not running after 330 s (state $state)" >&2; exit 1; }
  sleep 3
  state=$(job_state "$job")
  case "$state" in FAILED|NODE_FAIL|CANCELLED|TIMEOUT|OUT_OF_MEMORY|BOOT_FAIL) echo "FAIL: job $job ended $state" >&2; exit 1 ;; esac
done
cold_start=$((SECONDS - submitted))
until [ "$state" = COMPLETED ]; do
  [ $((SECONDS - submitted)) -lt 480 ] || { echo "FAIL: job $job did not complete (state $state)" >&2; exit 1; }
  sleep 3
  state=$(job_state "$job")
  case "$state" in FAILED|NODE_FAIL|CANCELLED|TIMEOUT|OUT_OF_MEMORY|BOOT_FAIL) echo "FAIL: job $job ended $state" >&2; exit 1 ;; esac
done
echo "    job $job COMPLETED; it waited ${cold_start}s for cold nodes"

echo "4/4 waiting for the nodes to power off again (up to 6 min)"
done_at=$SECONDS
until all_off; do
  [ $((SECONDS - done_at)) -lt 360 ] || { echo "FAIL: nodes not powered off again after 6 min" >&2; exit 1; }
  sleep 5
done
echo "elastic demo passed: cold start ${cold_start}s, back to powered off $((SECONDS - done_at))s after completion"
on_head tail -n 6 /var/log/slurm/power.log
```
