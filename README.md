# homelab

One command builds a three-node Kubernetes cluster on a Mac with Terraform and Ansible, deploys
[ley-khaa](https://github.com/ruttantai/ley-khaa) with Prometheus, Grafana and Loki, and tears it all down again.

Work in progress — see `docs/superpowers/specs/2026-10-01-homelab-design.md`.
